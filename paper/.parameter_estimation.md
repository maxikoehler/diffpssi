# Paper Idea: Parameter Identification for a Continuous Control Loop

> Using torch gradient calculation to perform a parameter estimation and optimzation for a continuous control substitution

---

## Background and Motivation

The general idea is mocking the discrete FSM module with a continuous control path, enabling sophisticated analytical stability analysis.
Therefore, a suitable continuous control path has to be found, which can represent the discrete behavior.
After that, all the individual parameters have to be found. 
The main problem here, is on the one side, that manual tuning is a complex and extensive task.
On the other side, the FSM with its capability to skip steps, must have individual parameters for each functional possibility.  
This work focusses only on the FSM path, not on the OLTC path.

### Optimization Approach

Mathematical formulation of the problem:
$$
\begin{alignat}{3}
    \min_{k_p,k_i,k_t} \quad &\frac{1}{N}\sum_{t \in T} (V_\mathrm{disc} - V_\mathrm{cont})^2 \\
    % \text{s.t.} \quad &\vartheta_\mathrm{lower} \leq \vartheta_t \leq \vartheta_\mathrm{upper}, \quad &&\forall t \in T \\
    % &
\end{alignat}
$$

The reference scenario could be:
- **a reference jump** (just voltage input jumps) -> good for parameter estimation and tuning on the individuals?
- **a load jump / short-circuit event** -> for discussion applied on a real "event"?
